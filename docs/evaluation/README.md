# Evaluation instruments

This folder holds the instruments and (once collected) the anonymized results for
requirement T5 and Chapter 6 of D1.

## Contents

| File | Purpose | Status |
|---|---|---|
| `chatbot-questions.json` | Question set for the AI integration evaluation | present (input) |
| `sus-instrument.md` | System Usability Scale questionnaire (10 items) | template |
| `iso25010-instrument.md` | ISO/IEC 25010 quality questionnaire | template |
| `consent-form.md` | Respondent consent form | template |
| `results/` | Anonymized responses and computed means | **empty — awaiting data** |

## Rules

- Each respondent signs a consent form before participating.
- Identities are replaced by codes `R1`, `R2`, … before any data is committed.
- Results must be the actual responses. Do not fill these files with simulated data.
- Report `n`, mean and interpretation per the rubric ranges.

Interpretation bands for the ISO/IEC 25010 5-point items:
`4.20–5.00 Excellent`, `3.40–4.19 Very Good`, `2.60–3.39 Good`, `1.80–2.59 Fair`, `1.00–1.79 Poor`.
For SUS, `68` is about average and `80+` is good.
