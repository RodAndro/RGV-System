# System Usability Scale (SUS)

Standard 10-item instrument (Brooke, 1996). 5-point scale: 1 = Strongly disagree … 5 = Strongly agree.
Respondents complete this **after** using the deployed system.

## Scoring

- Odd items: score − 1.
- Even items: 5 − score.
- Sum the ten adjusted scores, then multiply by 2.5 → 0–100.
