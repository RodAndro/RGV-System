## Getting Started

### Accessing the System

The RGV System is accessed via your web browser at the application URL provided by your administrator.

### Account Setup

1. Navigate to the login page (`/login`)
2. If you have an account, enter your email and password
3. If you are a new employee, an administrator will create your account and provide credentials

### Roles Overview

| Role | Access Level | Key Responsibilities |
|------|-------------|---------------------|
| **Public** | Booking form, booking tracking, AI chatbot | Submit and track service bookings |
| **Employee** | Employee dashboard, assigned bookings, borrow requests, inventory | Handle assigned work, request inventory |
| **Administrator** | Full system access | Manage users, bookings, inventory, reports, system configuration |

## Public User Guide

The public-facing features allow customers to book services and track their requests without creating an account.

### Submitting a Booking

1. Go to the homepage (`/`)
2. Click **"Book a Service"** or navigate to `/booking`
3. Fill out the booking form:

| Field | Description |
|-------|-------------|
| **Full Name** | Your complete name |
| **Email** | Valid email address for notifications |
| **Contact Number** | Phone number for service coordination |
| **Address** | Service location address |
| **Preferred Date** | Date you want the service performed |
| **Preferred Time** | Preferred time slot |
| **Purpose Category** | Type of service needed |
| **Reason** | Detailed description of the service request |
| **Attachment** | Optional: Upload relevant files (photos, documents) |

4. Click **"Submit Booking"**
5. Save the **reference number** shown on the confirmation page (format: `BK-XXXXXXXXXXXXX`)

### Tracking a Booking

1. Navigate to `/booking/track/{reference}` or use the tracking form on the homepage
2. Enter your booking reference number
3. View the current status of your booking

**Booking Statuses:**

| Status | Meaning |
|--------|---------|
| **Pending** | Booking received, awaiting review |
| **Approved** | Booking confirmed, employee assigned |
| **Rejected** | Booking declined (check remarks for reason) |
| **Completed** | Service has been performed |
| **Cancelled** | Booking has been cancelled |

### Using the AI Chatbot

1. Click the chat icon on any public page
2. Type your question about RGV services, booking process, or general inquiries
3. The AI assistant responds with relevant information

## Employee Guide

Employees manage assigned bookings, request to borrow inventory items, and view the inventory catalog.

### Logging In

1. Navigate to `/login`
2. Enter your email and password
3. If Multi-Factor Authentication (MFA) is enabled, enter the verification code sent to your email or generated by your authenticator app
4. You will be redirected to your dashboard

### Employee Dashboard

The dashboard provides an overview of:

- **Your assigned bookings** — pending and upcoming
- **Your borrow requests** — active and pending
- **Notifications** — recent updates
- **Quick stats** — summary of your work

### Managing Assigned Bookings

1. Go to **Bookings** in the employee navigation
2. View all bookings assigned to you
3. Click on a booking to view full details
4. Update the booking:
   - **Add remarks** — Notes about the service visit
   - **Update status** — Change as work progresses
   - **View customer details** — Contact information, address, attachments

### Borrowing Inventory

#### Submitting a Borrow Request

1. Navigate to **Borrow Requests** → **New Request**
2. Select the inventory items you need
3. Specify the quantity for each item
4. Set the borrow date and expected return date (due date)
5. Provide a reason for borrowing
6. Submit the request

**Borrow Request Statuses:**

| Status | Meaning |
|--------|---------|
| **Pending** | Awaiting admin approval |
| **Approved** | Approved, items ready for pickup |
| **Rejected** | Request declined (check admin remarks) |
| **Borrowed** | Items currently in your possession |
| **Returned** | Items returned and logged |
| **Overdue** | Past due date, items not yet returned |

#### Returning Items

1. Go to your active borrow request
2. Mark items as returned
3. Report the condition of each returned item (good/fair/poor)
4. Add any damage notes if applicable

### Viewing Inventory

1. Navigate to **Inventory** in the employee menu
2. Browse items by category
3. View item details: name, description, quantity, condition, location
4. Check stock availability before requesting items

### Managing Notifications

1. Click the bell icon in the top navigation bar
2. View all notifications
3. Click a notification to go to the related item
4. Mark individual notifications as read, or use **"Mark All as Read"**

### Profile Settings

1. Click your name/avatar → **Profile**
2. Update your personal information
3. Configure notification preferences:
   - Toggle email notifications on/off per notification type
   - Toggle in-app notifications on/off per notification type
4. Enable/disable MFA for additional security

## Administrator Guide

The administrator has full control over the RGV System including user management, booking management, inventory, reports, and system configuration.

### Admin Dashboard

The admin dashboard (`/admin/dashboard`) shows:

- **Booking stats** — Total, pending, approved, completed today
- **Inventory stats** — Total items, low stock alerts, borrowed items
- **User stats** — Active users, new registrations
- **Recent activity** — Latest bookings, borrow requests, user actions

### Booking Management

#### Viewing and Filtering Bookings

1. Navigate to **Admin** → **Bookings**
2. Filter by:
   - **Status** — pending, approved, completed, rejected, cancelled
   - **Date range** — Filter by preferred date
   - **Search** — By reference number, name, or email
3. Click any booking to view full details

#### Processing Bookings

1. Open a booking from the list
2. Review customer details, preferred date/time, purpose, and reason
3. Choose an action:

| Action | Result |
|--------|--------|
| **Approve** | Booking confirmed. Assign an employee. Customer notified. |
| **Reject** | Provide rejection reason. Customer notified. |
| **Complete** | Mark service as finished. |
| **Cancel** | Cancel the booking. Optional remarks. |

#### Assigning Employees

1. After approving a booking, click **"Assign Employee"**
2. Select an available employee from the dropdown
3. Employee is notified of the new assignment

#### Calendar View

1. Navigate to **Bookings** → **Calendar**
2. View all bookings in a calendar format
3. Click any booking to see details
4. Useful for scheduling and workload planning

#### Generating Booking Invoices

1. Open a booking
2. Click **"Generate Invoice"**
3. A PDF invoice is generated with customer and service details

### Inventory Management

#### Viewing Inventory

1. Navigate to **Admin** → **Inventory**
2. Browse all inventory items
3. Filter by category, status, or search by name/item code
4. View the **Low Stock** page for items below their threshold

#### Adding Inventory Items

1. Click **"Add Item"**
2. Fill in the item details:

| Field | Description |
|-------|-------------|
| **Item Code** | Unique identifier (auto-generated or manual) |
| **Name** | Item name |
| **Description** | Detailed description |
| **Category** | Select from existing categories |
| **Supplier** | Select supplier or add new |
| **Quantity** | Initial stock count |
| **Unit** | pcs, box, kg, etc. |
| **Unit Cost** | Cost per unit |
| **Status** | available, maintenance, damaged |
| **Condition** | new, good, fair, poor |
| **Location** | Storage location |
| **Low Stock Threshold** | Alert when quantity falls below this number |
| **Image** | Upload item photo |

3. Click **"Save"**

#### Editing Inventory Items

1. Click an item → **Edit**
2. Modify any fields
3. Click **"Update"**

#### QR Code Generation

1. Open an inventory item
2. Click **"Generate QR Code"**
3. A QR code is created linking to the item details
4. Print and attach to the physical item for easy scanning

#### Deleting Items

1. Click the delete action on an inventory item
2. Item is soft-deleted (moved to trash)
3. Items in trash can be restored or permanently deleted

### Borrow Request Management

#### Approving/Rejecting Requests

1. Navigate to **Admin** → **Borrow Requests**
2. Filter by status (focus on pending requests)
3. Open a request to view:
   - Requesting employee
   - Items and quantities requested
   - Reason for borrowing
   - Borrow and due dates
4. Choose an action:

| Action | Result |
|--------|--------|
| **Approve** | Items are marked as borrowed. Employee notified. Stock adjusted. |
| **Reject** | Provide reason. Employee notified. |

#### Monitoring Overdue Items

- The system automatically marks borrow requests as **overdue** when past the due date
- Review overdue items regularly
- Contact employees about late returns
- Add penalty notes as needed

### User Management

#### Viewing Users

1. Navigate to **Admin** → **Users**
2. View all registered users
3. Filter by role, status (active/inactive), or search by name/email

#### Creating Users

1. Click **"Add User"**
2. Fill in user details:
   - Name, email, password
   - Role: Admin or Employee
   - Phone, address
3. Click **"Create"**

#### Managing Users

1. Click a user to view their profile, activity, and stats
2. Available actions:

| Action | Description |
|--------|-------------|
| **Edit** | Update user details |
| **Toggle Status** | Activate/deactivate user account |
| **Force Logout** | Terminate all active sessions |
| **Impersonate** | Log in as the user to troubleshoot |

#### Impersonation

1. Click **"Impersonate"** on a user
2. You are now logged in as that user
3. A banner appears indicating impersonation mode
4. Click **"Stop Impersonating"** to return to your admin account
5. All impersonation sessions are logged

#### User Analytics

1. Navigate to **Users** → **Analytics**
2. View user metrics:
   - Registration trends
   - Active user counts
   - Role distribution
   - Login activity

### Reports

#### Available Reports

| Report Type | Description |
|-------------|-------------|
| **Booking Reports** | Booking volume, status distribution, by date range |
| **Inventory Reports** | Stock levels, low stock items, inventory movement |
| **Borrow Reports** | Borrow request trends, overdue items, employee activity |
| **User Reports** | User activity, login history |

#### Generating Reports

1. Navigate to **Admin** → **Reports**
2. Select the report type
3. Set date range filters
4. View the report data on screen
5. Export options:
   - **PDF** — Download as formatted PDF
   - **Excel** — Download as spreadsheet
   - **CSV** — Download as comma-separated values

### AI-Powered Reports

1. Navigate to **Admin** → **AI**
2. Available AI features:

| Feature | Description |
|---------|-------------|
| **AI Insights** | AI-generated analysis of business data and trends |
| **Booking Forecast** | AI prediction of future booking volumes |
| **Inventory Recommendations** | AI suggestions for stock levels and reorder points |

### Import & Export

#### Importing Data

1. Navigate to **Admin** → **Import/Export**
2. Select import type (Inventory or Users)
3. Download the template file (optional)
4. Upload your CSV or Excel file
5. Select duplicate strategy:
   - **Skip** — Ignore duplicate entries
   - **Update** — Update existing records
   - **Error** — Stop and report error
6. Click **"Import"**
7. Monitor progress in the import log
8. Download error report if any records failed

#### Exporting Data

1. Navigate to **Admin** → **Import/Export**
2. Select export type (Inventory, Bookings, or Users)
3. Apply filters to narrow down the data
4. Select columns to include
5. Choose format (Excel, CSV, PDF)
6. Click **"Export"**
7. Download the generated file from the export log

### Notifications (Admin)

1. Click the bell icon in the top navigation
2. View all system notifications
3. Actions:
   - Click to open/view details
   - Mark individual as read
   - **"Mark All as Read"** — Mark all read
   - Delete individual notifications
   - **"Clear All"** — Remove all notifications

### Audit Logs

1. Navigate to **Admin** → **Audit Logs**
2. View all system activity:
   - User actions (login, logout, data changes)
   - Model changes (created, updated, deleted)
   - Impersonation sessions
   - Import/export operations
3. Filter by:
   - Event type
   - User
   - Date range
4. Export audit logs for compliance purposes

### Backups

1. Navigate to **Admin** → **Backups**
2. View existing backups with size, SHA-256 checksum status, and status message
3. Click **"Run Manual Backup"** to create a new backup immediately
4. **Download** — Click the Download button to retrieve a backup `.zip` file
5. **Verify** — Click Verify to re-check the file integrity against its recorded checksum
6. **Settings** — Configure notification email, admin update email, and S3 cloud storage toggle
7. Backups include:
   - Database dump (SQLite)
   - Application files (app, config, database, public, resources, routes, storage, .env)
8. Scheduled backups:
   - Full backup: Daily at 2:00 AM
   - Database-only: Weekly Sundays at 3:00 AM
   - Cleanup old backups: Daily at 3:30 AM

#### Retention Policy
- Keep all backups: 1 day
- Daily backups: 7 days
- Weekly backups: 4 weeks
- Monthly backups: 12 months
- Yearly backups: 2 years
- Maximum storage: 5000 MB

#### Admin Email Notifications
Emails are sent to the configured admin email (`ADMIN_NOTIFICATION_EMAIL`) when:
- A booking status changes (approved, rejected, completed, etc.)
- An inventory item is created, updated, or deleted
- A borrow request status changes
- A backup completes or fails

Configure the admin email in **Backup Settings** or **Site Settings → Backup**. Global email notifications can be disabled in **Site Settings → Notifications**.

### Trash Management

Soft-deleted items are moved to the trash, not permanently removed. Supported types: Bookings, Borrow Requests, Inventory, Inventory Categories, Suppliers.

1. Navigate to **Admin** → **Trash**
2. Filter by type using the tabs (each shows a count of trashed items)
3. View deleted items with their identifier, type, and deletion timestamp
4. Actions:
   - **Restore** — Recover a deleted item to its original state
   - **Delete Permanently** — Requires password confirmation; permanently removes the item

**Note:** Employees can soft-delete their own returned or rejected borrow requests from the employee portal. These appear in the admin Trash under "Borrow Request".

### Site Settings

Administrators can configure system-wide settings through **Admin** → **Site Settings**. The page has 7 tabs:

| Tab | Configurable Settings |
|-----|----------------------|
| **Branding** | Site name, tagline, accent color |
| **Email** | SMTP host, port, encryption, scheme, username, password, from address/name |
| **Security** | Password minimum length, session lifetime, max login attempts |
| **Backup** | Backup notification email, admin update email, S3 toggle |
| **Notifications** | System notification email, global email notification toggle |
| **Maintenance** | Enable/disable maintenance mode, custom message, allowed IPs |
| **API** | Rate limits for public, standard, premium, and admin tiers |

Changes are saved directly to the `.env` configuration file and take effect immediately.

### PDF Export (Direct)

Quick PDF generation from listing pages:

1. Navigate to **Admin** → **Export** → **Bookings** — Export all bookings as PDF
2. Navigate to **Admin** → **Export** → **Inventory** — Export inventory list as PDF
3. Open a specific booking → **Export Booking** — Generate individual booking PDF

## Troubleshooting

### Common Issues

| Issue | Solution |
|-------|----------|
| **Can't log in** | Verify email and password. Use "Forgot Password" if needed. Check if your account is active. |
| **MFA code not received** | Check spam folder for email codes. Click "Resend Code". For TOTP, ensure device time is synchronized. |
| **Access denied (403)** | Your role may not have permission. Contact an administrator. |
| **Booking reference not found** | Verify the reference number format (`BK-XXXXXXXXXXXXX`). Check for typos. |
| **Import fails** | Ensure file matches the template format. Check the error report. Review duplicate strategy settings. |
| **PDF not generating** | Check that the data is complete. Try regenerating. Large exports may take longer. |
| **Slow performance** | Large data exports may take time. Filter data before exporting. Contact admin for system performance issues. |

### Getting Help

- **AI Chatbot**: Available on public pages for immediate assistance
- **In-app notifications**: Check for system announcements
- **Administrator contact**: For account issues, contact your system administrator

## Keyboard Shortcuts & Tips

### Navigation Tips

- Use the sidebar menu to switch between sections
- Breadcrumb navigation shows your current location
- The bell icon shows unread notification count
- Click your avatar for profile and logout options

### Data Entry Tips

- Date fields accept date picker selection or manual entry (YYYY-MM-DD)
- Required fields are marked with an asterisk (*)
- Forms will highlight validation errors before submission
- Large tables support pagination — adjust items per page as needed

### Security Best Practices

- Log out after each session, especially on shared computers
- Enable MFA for additional account security
- Do not share your password or MFA recovery codes
- Review your notification preferences regularly
- Report suspicious activity to the administrator
