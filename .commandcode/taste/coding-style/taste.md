- Prefers not fabricating or guessing missing data values; uses `NULL`/defaults/empty fields and flags ambiguous records for review rather than assuming. Confidence: 0.9

Keep such widgets as per-view includes (e.g., `<x-chatbot pageType="reports" />`) in the five `resources/views/admin/reports/*.blade.php` views — not in `layouts/admin`, `layouts/employee`, `layouts/app`, `layouts/guest`, or the standalone public views — and leave Alpine.js CDN / `[x-cloak]` / CSRF meta off public pages unless the user explicitly asks. Admin-only widgets stay admin-only (admin-only views plus admin middleware on the endpoint). Confidence: 0.85
- User is sensitive to subtle visual artifacts on images: a 1–2px Tailwind `ring-*` outline on the logo `<img>` tags reads as an unwanted "border" to them ("theres a border on the logo remove it"). Strip `ring`/`ring-*` classes from logo/image markup rather than leaving decorative outlines, and apply the fix to every logo instance project-wide (public views, layouts, sidebar partials).
